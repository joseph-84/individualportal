# Portal 즐겨찾기 추가 (크롬 익스텐션)

개인 포털(individualPortal)의 즐겨찾기에 현재 보고 있는 탭을 바로 추가하는 크롬 익스텐션입니다.
개인 전용으로 만든 것이라 크롬 웹 스토어에 올리지 않고 "개발자 모드"로 로드해서 씁니다.

## 설치

1. `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 `chrome-extension` 폴더 선택

## 설정

1. 포털의 `/account` 페이지 → **API 토큰** 섹션에서 토큰을 발급합니다(이름만 붙이면 됩니다).
   토큰 값은 발급 시 한 번만 표시되니 바로 복사하세요.
2. 익스텐션 아이콘 우클릭 → **옵션**(또는 `chrome://extensions`에서 이 익스텐션의 "세부정보" →
   "확장 프로그램 옵션") → **포털 URL**(예: `https://portal.example.com`)과 방금 발급한
   **API 토큰**을 입력하고 저장합니다.

## 사용

즐겨찾기로 남기고 싶은 페이지에서 익스텐션 아이콘을 클릭하면, 현재 탭의 제목/URL이 채워진
작은 팝업이 뜹니다. 필요하면 제목을 다듬거나 폴더를 입력(기존 폴더는 자동완성됩니다)한 뒤
**저장**을 누르면 끝입니다.

## 동작 방식 / 권한에 대해

- 새 백엔드 API를 만들지 않고, 포털이 이미 제공하는 MCP 엔드포인트(`/mcp`)의 `create_favorite`/
  `list_favorites` 도구를 그대로 호출합니다(`mcp-client.js`) — 인증은 `/account`에서 발급한
  API 토큰 그대로입니다.
- `manifest.json`의 `host_permissions`가 `<all_urls>`로 넓게 설정되어 있습니다. 포털 주소가
  사용자마다 다른 자체 호스팅 도메인이라 미리 고정할 수 없고, 웹 스토어에 올려 심사받는 게
  아니라 본인만 쓰는 unpacked 익스텐션이라 이렇게 단순하게 처리했습니다. 다른 사람에게 배포할
  계획이라면 더 좁은 권한 모델(예: 포털 도메인 설정 시 `chrome.permissions.request`로 그
  도메인만 동적으로 요청)로 바꾸는 걸 권장합니다.
